This is a repository that contains all of the raw data for cobalt analyses via ICP-MS, live plate counts, phenazine measurements, dose-response data, and electrochemical analyses associated with a manuscript investigating microbially-induced corrosion of elemental cobalt by _Pseudomonas_ _chlororaphis_ subspecies _aureofaciens_. A dedicated R notebook has also been included for the metabolomic workflow developed in this work, to be used in tandem with Feature Based Molecular Network (FBMN). 
All files serve as inputs for regenerating the figures listed in the headers of the associated R notebooks provided in markdown format.
